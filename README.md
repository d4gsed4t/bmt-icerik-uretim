# BMT Post Üretici

ETÜ Bilgisayar Mühendisliği Topluluğu'nun paylaşımlarını görsel kimliğe uygun üretir: şablonu seç,
içeriği yaz, kaydet. Telefonda ve bilgisayarda tarayıcıdan çalışır; ana ekrana uygulama olarak eklenebilir.

**Kullan:** https://d4gsed4t.github.io/bmt-icerik-uretim/
